# Partially Ordered

Static Astro port of partiallyordered.com. Tailwind is loaded through its Vite plugin, and the pages use only locally served visual, icon, and MathJax resources.

Published article source is kept in `src/article-source/posts/`. Its diagrams are in `public/posts/`, and the locally served MathJax runtime is in `public/vendor/mathjax/`.

```sh
npm install
npm run dev
npm run build
```
